# 协作与个人职责

| 角色 | 责任 |
| --- | --- |
| 项目所有者 | 真实问题、功能取舍、测试岗位、试用与最终报告意见 |
| Codex | 架构、接口、认证权限、数据库、模型与证据规则、调试、审查与集成 |
| WorkBuddy | 冻结输入和文件边界内的展示组件、Mock、响应式与交接 |

原工程按独立工作目录交付，任务包含基线、允许路径、禁止路径、契约、验收与提交号。署名区分实际实现者和审查者，不能把 Codex 代实现写成 WorkBuddy 实现。

当前两个公开仓库独立：Job Copilot 按阶段完善核心能力，portfolio-site 由新前端代理继续开发。新代理只在网站仓库工作，不能读取私有凭证、连接 Job Copilot 服务或更改核心仓库。核心迭代的范围与时间由用户决定。
